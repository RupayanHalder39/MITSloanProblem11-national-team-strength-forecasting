## Two placeholders remain in the approved PDF

Both were present in the approved file and are deliberately left as they are,
because filling them in would mean editing the approved artifact or inventing
an identifier.

1. **`Soccer Paper ID: [To be assigned]`** — the conference identifier had not
   been issued when the paper was approved. No identifier is invented here.
2. **`Open-source repository: [PUBLIC ANONYMIZED GITHUB URL REQUIRED BEFORE
   SUBMISSION]`** — to be resolved before submission, with the venue's
   anonymisation requirement in mind. The public repository for this work is
   <https://github.com/RupayanHalder39/MITSloanProblem11-national-team-strength-forecasting>.

**Action required before submitting the paper:** resolve both placeholders in
the submission copy. Neither affects any result published in this repository.
